# DealNest - Price Compare

DealNest is a Chrome extension for comparing prices across captured marketplace listings.

## Download

Get the extension ZIP from the [DealNest download page](https://lupin-69.github.io/dealnest-chrome-web-store/).

## Install in Chrome

1. Download and extract the ZIP.
2. Open `chrome://extensions` in Chrome and enable **Developer mode**.
3. Select **Load unpacked** and choose the extracted extension folder.
